# คู่มือการติดตั้งระบบฝากขาย OTC (Google Apps Script)

ระบบจัดการฝากขายสินค้า OTC แบบแยกหน้าเว็บใช้งานระหว่างแอดมิน (Web App Admin) และพนักงานในพื้นที่ (Mobile App Sale) บนฐานข้อมูล Google Sheet เดียวกัน พร้อมฟังก์ชันการทำธุรกรรม, การควบคุมสต็อก 2 ระดับ, ระบบบันทึกการขายพร้อมรูปหลักฐาน และระบบยกเลิกรายการ (Rollback)

---

## ส่วนประกอบของไฟล์ในโปรเจกต์
คุณสามารถนำโค้ดในไฟล์เหล่านี้ไปวางในโปรเจกต์ Google Apps Script (ในรูปแบบ HTML/Script) ดังนี้:

1. **`Code.gs`** (ไฟล์รหัสสคริปต์หลัก): ควบคุมการทำ Routing, API และจัดการการปรับปรุงสต็อก (Inventory State Machine)
2. **`Index.html`** (ไฟล์เทมเพลตเริ่มต้น): สำหรับควบคุม Single-Page Application (SPA) และสิทธิ์การเข้าใช้งาน
3. **`LoginPanel.html`** (ไฟล์หน้าจอล็อกอิน): ล็อกอินแบบ Username & Password (จากตาราง `tb_users`)
4. **`AdminPanel.html`** (ไฟล์หน้าจอแอดมิน): ควบคุมการอนุมัติ, ตรวจสต็อกรวม, จัดการข้อมูล Master Data และออกสลิป PDF
5. **`MobilePanel.html`** (ไฟล์หน้าจอเซลล์): หน้าจอแบบแอปมือถือ ตรวจสอบสต็อกตนเอง, แจ้งเบิก/ฝากขาย/ขายจริงพร้อมอัปโหลดสลิปจากกล้องมือถือ, และตรวจส่งคืนสินค้า

## ขั้นตอนการติดตั้งและเปิดใช้งาน

### ขั้นตอนที่ 1: เตรียมทรัพยากรบน Google Drive
1. **สร้าง Google Sheet ใหม่**: สร้าง Google Sheet ว่างเปล่าขึ้นมา 1 ไฟล์ และคัดลอก **Spreadsheet ID** จาก URL (เช่น `https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit`)
2. **สร้างโฟลเดอร์ Google Drive**: สร้างโฟลเดอร์สำหรับจัดเก็บรูปภาพหลักฐานธุรกรรมของเซลล์ และคัดลอก **Folder ID** จาก URL (เช่น `https://drive.google.com/drive/folders/FOLDER_ID`)

### ขั้นตอนที่ 2: ตั้งค่าโปรเจกต์ Google Apps Script
1. เปิด Google Sheet ที่สร้างขึ้น -> ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
2. ลบโค้ดเริ่มต้นออก และทำการสร้างไฟล์ต่างๆ ในระบบของ Apps Script ให้ตรงตามชื่อและสกุลไฟล์:
   - เปลี่ยนชื่อ `Code.gs` และนำโค้ดจาก `Code.gs` ในโฟลเดอร์นี้ไปใส่
   - กดปุ่ม **+ (เพิ่มไฟล์)** -> เลือก **HTML** -> ตั้งชื่อว่า `Index` (ไม่ต้องใส่ `.html`) -> ใส่โค้ดจาก `Index.html`
   - เพิ่มไฟล์ HTML ชื่อ `LoginPanel` -> ใส่โค้ดจาก `LoginPanel.html`
   - เพิ่มไฟล์ HTML ชื่อ `AdminPanel` -> ใส่โค้ดจาก `AdminPanel.html`
   - เพิ่มไฟล์ HTML ชื่อ `MobilePanel` -> ใส่โค้ดจาก `MobilePanel.html`
3. กดบันทึกโครงการ (รูปแผ่นดิสก์)

### ขั้นตอนที่ 3: เริ่มต้นฐานข้อมูล (Database Initialization)
1. ในหน้า Apps Script ให้เลือกฟังก์ชัน `initDatabase` จากแถบเมนูด้านบน
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. ระบบจะขอสิทธิ์การเข้าถึงไฟล์ (Authorization) ให้เลือกบัญชี Google ของคุณ -> กด Advanced -> เลือก Go to ... (unsafe) -> กด Allow
4. หน้าต่างบันทึกจะแสดงข้อความว่าสร้างตารางเรียบร้อยแล้ว ใน Google Sheet ของคุณจะมีตารางใหม่ปรากฏขึ้นมา 5 ตาราง:
   - `tb_users` (ระบบจะใส่บัญชีแอดมินเริ่มต้นให้โดยอัตโนมัติ: **Username**: `admin` / **Password**: `admin1234`)
   - `tb_products`
   - `tb_stores`
   - `tb_inventory`
   - `tb_transactions`

### ขั้นตอนที่ 4: การนำไปใช้งาน (Web App Deployment)
1. กดที่ปุ่ม **การจัดทำใช้งาน (Deploy)** มุมขวาบน -> เลือก **การจัดการการจัดทำใช้งานใหม่ (New Deployment)**
2. คลิกที่รูปฟันเฟือง (Select type) -> เลือก **เว็บแอปพลิเคชัน (Web App)**
3. ตั้งค่าการกำหนดค่าดังนี้:
   - **รายละเอียด (Description)**: เวอร์ชันเริ่มต้น
   - **เรียกใช้งานในฐานะ (Execute as)**: **ฉัน (Me / บัญชีแอดมิน)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)** *(เพื่อให้เซลล์สามารถเปิดใช้งานได้โดยไม่ต้องล็อกอินบัญชี Google)*
4. กด **จัดทำใช้งาน (Deploy)**
5. คัดลอกลิงก์ **URL เว็บแอป (Web App URL)** ที่ระบบให้มา เพื่อนำไปใช้งาน:
   - **สิทธิ์แอดมินและสิทธิ์เซลล์ทั่วไป**: เปิดใช้งานและล็อกอินผ่านลิงก์เดียวกันได้ทันที ระบบจะตรวจสอบสิทธิ์และสลับหน้าจอ (Admin Panel หรือ Mobile App) ให้โดยอัตโนมัติอ้างอิงจากบทบาทในชีท `tb_users`
